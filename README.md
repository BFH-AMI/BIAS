# The BIAS Project: NLP Demonstrators

This work is part of the Europe Horizon project BIAS funded by the European Commission, and has received funding from the Swiss State Secretariat for Education, Research and Innovation (SERI).

This repository gives an overview of the different open source releases from the project. An overview of all the research of the Natural Language Processing (NLP) components can be found at: https://nlpdemo.biasproject.eu

## The BIAS Detection Framework
In the BIAS project, we have investigated how real-world biases (that were identified with co-creation activities, literature searches and interaction with the interdisciplinary consortium) are reflected in resources from natural language processing (NLP) for European languages. Here we present our novel bias metrics, BIAS-WEAT and BIAS-SEAT, for different European languages and the results of our research. 

Repository: https://github.com/BFH-AMI/BIAS-DetectionFramework

## The BIAS Mitigation Framework
The BIAS Mitigation Framework contains code for conducting adversarial bias mitigation experiments on BERT and RoBERTa models in a variety of languages, focusing on reducing gender bias in occupation prediction tasks. The code supports both BERT and RoBERTa architectures and includes tools for intrinsic bias evaluation using WEAT/SEAT/LPBS tests.

Repository: https://github.com/BFH-AMI/BIAS-MitigationFramework

## The BIAS Smarter Prompting Demonstrator
This BIAS Demonstrator optimizes user prompts to obtain less biased results when prompting LLMs. Drawing on the latest research from the ethnographic field studies and NLP research of the BIAS project into how LLMs mirror societal biases, we created a multi-model pipeline that reframes user prompts. This tool was developed in collaboration with scholars from the social sciences and humanities (SSH).

Repository: https://github.com/BFH-AMI/BIAS-SmarterPromptingDemonstrator

## The BIAS LLM-as-a-Judge Framework
The BIAS LLM-as-a-Judge Framework evaluates LLM answers for bias, inclusivity, and stereotype-free language using Large Language Models (LLMs) as judges. It processes Excel files containing both original and adapted (improved) prompts, evaluates them across multiple criteria, and generates comprehensive statistical analyses and visualizations.

Repository: https://github.com/BFH-AMI/BIAS-LLM-as-a-Judge
